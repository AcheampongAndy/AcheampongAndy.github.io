# Andrews Acheampong — Academic Website

A static, responsive academic personal website designed with a simple navigation and typographic style inspired by the structure of [Allard Lab](https://www.allardlab.com/). This is an independent design and does not copy its code, images, or content.

## Pages
- `index.html`: Home
- `research.html`: Research
- `projects.html`: Computational projects
- `teaching.html`: Teaching and service
- `cv.html`: Academic CV overview
- `contact.html`: Contact information

## Updating the website
1. Edit the HTML files to update text.
2. Edit `assets/style.css` to change colors, fonts, or spacing.
3. Replace `assets/Andrews_Acheampong_CV.pdf` with your newest CV using **the same filename**.
4. Replace `assets/favicon.jpg` with your own favicon if desired.

## Publish with GitHub Pages
1. Unzip the download.
2. Upload the contents **inside** `AcheampongAndy_Allard_Style_Website` to the root of your existing `AcheampongAndy.github.io` repository (not the outer folder).
3. Commit and push to the `main` branch.
4. In repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)` if necessary.
5. Open `https://acheampongandy.github.io/` after GitHub Pages deploys the changes.

The project uses plain HTML/CSS and does not require Jekyll, Node, or a build step.
