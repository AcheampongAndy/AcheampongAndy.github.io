# Andrews Acheampong Academic Website

A simple black-and-white academic website styled after mathematics/statistics faculty homepages.

## This revision includes

- removal of the "Current research" section from the homepage
- removal of all research-slide links
- a research page focused only on research interests and completed work
- improved display of the homepage name block
- reuse of the favicon from the original website (`assets/favicon.jpg`)

## Files

- `index.html` — homepage
- `research.html` — research interests and completed work
- `assets/style.css` — site styling
- `assets/Andrews_Acheampong_CV.pdf` — CV
- `assets/favicon.jpg` — favicon reused from the previous website
